# Verified Facts

The reusable BuildX reference: pricing, statistics, recurring facts, commonly referenced
numbers, myths versus facts, and wording that has been verified.

**Source-of-truth: authoritative.** These figures are currently scattered across per-clip
notes in the project clip plans, where the qualifier attached to one of them lives inside a
single clip's trim note while applying to every future piece that reuses the number. This
file consolidates them so each is checked once.

**Every figure here was spoken on camera** during the documented Home Tour footage
(2026-07-25) and appears in the transcripts. Nothing has been inferred, rounded or
extrapolated.

---

## How to use this file

Every entry carries a mark:

| Mark | Meaning |
|---|---|
| ✅ | **Verified.** Use as stated. |
| ⚠️ | **Requires a qualifier.** The stated caveat travels with the figure — on screen, in captions, and in copy. Not optional. |
| ⛔ | **Never present as fact.** Usable only as the claim being corrected. |

And a **`verified` date**, because several of these move.

Treat this document as the authoritative reference whenever a reusable fact appears in
multiple projects.

> **Check this file before any number reaches the screen.** That is a step in the caption
> review pass and in the pre-export QA gate — see `captions.md` and
> `production-workflow.md`.

**When in doubt, defer to a direct correction over the transcript.** Where a spoken figure
has been corrected afterwards, the correction wins. See `terminology.md`.

## Myths vs facts

The reusable form of the content. Each row is a real, held belief and the on-camera
correction.

| Myth | Fact | Mark |
|---|---|---|
| "You can build an ADU for $150,000" | Not at this quality. **$440K–$460K all-in** for the documented 900 sq ft build | ✅ |
| "800 sq ft will be cheaper than 900" | Almost the same price — **you're paying for a slice of the building.** Kitchen, septic, survey, electrical, heating and bath are the same either way | ✅ |
| "An ADU can never be sold separately" | Ownership can be placed into a **condominium association with an exclusive use area**, after which it could be sold | ⚠️ **The speaker's hedge is mandatory — see below** |
| "A covered porch counts toward square footage" | Not if it is **unheated and unenclosed** | ✅ |
| "Permitting is a nightmare" | It simply takes time — **roughly four months** | ✅ |
| "Building smaller saves money" | It leaves square footage behind for no meaningful saving. *"Why leave 100 square feet behind?"* | ✅ |
| "A standard model means no choices" | Everything customises from a standard starting point | ✅ |
| "Any contractor can advise on an ADU" | Much of what is being told to homeowners is, in the speaker's words, **"dead wrong"** | ✅ |
| "You must do a 99-year ground lease" | A condominium split is an alternative | ⚠️ Same hedge as the separate-sale claim |

## Verified wording

Where phrasing itself has been checked, or where a qualifier is **mandatory**. These are the
entries most likely to be lost when a figure is lifted out of context.

### Mandatory qualifiers

| Claim | The qualifier that must travel with it |
|---|---|
| **$40,000 at foundation** | Caption as an **example only.** The speaker says "made up number" while giving it |
| **Selling an ADU separately** | Keep **"I haven't proven this yet."** The hedge is what makes the claim publishable. **Never caption it as settled law** |
| **The 1,300 sq ft cap** | State that it is **pending Attorney General approval** and not yet in force |
| **The 4-of-6 / 80% statistic** | Ships **without the town name** |
| **The 3.5-month permit timeline** | Identify it as **one project's experience**, not a general expectation |

|---|---|---|

### Phrases that carry the brand

Verified verbatim, and reusable as-is:

- *"You're really just paying for a slice of the building."*
- *"Why leave 100 square feet behind?"*
- *"We do everything except tuck you into bed."*
- *"What I'm telling you is truth."*
- *"Zoning and permits are one thing, but they can't dictate ownership."*
- *"Remember, just build baby."*

Use them as quotations of what was said. They should remain verbatim unless the original
recording itself changes. **They do not license paraphrase** — see `editorial.md`.

## Maintaining this file

- **Date every entry.** A figure without a date becomes a false claim quietly.
- **Re-verify statistics quarterly at minimum.** Counts of completed and in-progress
  projects move fastest.
- **When a figure is superseded, replace it and note the date** — do not accumulate historical
  values here. Superseded figures belong in the project record.
- **A new figure enters this file only when it has been spoken on camera or confirmed
  directly.** Not from a website, not from an assumption, not from a similar project.
- **Qualifiers are part of the entry, not a footnote to it.**
- **Remove obsolete entries rather than allowing conflicting current values to accumulate.**
  Historical figures belong in project documentation, not the reusable reference.
